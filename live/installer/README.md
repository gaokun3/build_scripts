# gaokun3 图形安装器

LiveCD 上的图形安装流程。**直接画 KMS，不装合成器** —— weston/wayland
一整套对一个只有七屏的安装器来说太重，而镜像体积目标是 ≤120 MiB。

## ★ 两个渲染后端

| 后端 | 用途 |
|---|---|
| **PNG** | 离线把每一屏写成图片。**不需要目标硬件** |
| **DRM** | 设备上画到 KMS dumb buffer |

这不是顺手加的调试功能，是这个安装器**能被开发出来的前提**：目标机器同时是
作者的日用平板，经常拿不到。没有离线渲染，改一行文案都要排队等上机。

```sh
make shots      # 生成 shots/*.png，14 张，覆盖每一屏和几个关键状态
make drm        # 设备构建（在 Alpine chroot 里）
```

## 分区逻辑不在这里

图形前端**不实现任何分区逻辑**，全部转给
[`scripts/live/installer-lib.sh`](../../scripts/live/installer-lib.sh)
（`gk3_probe` / `gk3_plan` / `gk3_apply`），命令行安装器用的是同一份代码。
★ 一套后端两个前端 —— 本仓反复吃过"两份拷贝各自漂移"的亏。

后端的方案计算有离线自测：`bash scripts/live/test-plan.sh`，
重点验两条会毁数据的不变量：**分区不重叠、不越界**。

## 界面上的几个决定

* **逻辑坐标固定 1280×800**，输出时整体缩放。面板物理是 1600×2560 竖屏，
  平板横着用，所以 DRM 后端旋转 90°。
* **触摸目标最小 88 逻辑像素**。这机器没有鼠标，手指的实际接触面积
  远大于设计稿上看着的那点。
* **最后一步是"按住 2 秒"而不是点一下**。触摸屏误触太容易，而那一步不可撤销。
* **双系统模式在做不到时是禁用 + 写明原因**，不是直接藏起来 ——
  "为什么没有这个选项"本身就是用户需要的信息。
* 字体写 `Sans` 交给 fontconfig（镜像里装了 wqy-zenhei，中文自动回退）。
  写死字体名会在换字体包时静默变成方框。
